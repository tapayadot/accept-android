Accept

object Accept

Entry point to the Accept SDK.

Before using the SDK, it must be initialized once, typically from your android.app.Application.onCreate:

class MyApplication : Application() {
    override fun onCreate() {
        super.onCreate()
        Accept.initialize(this, isProduction = false) // Target sandbox
    }
}
Content copied to clipboard

Once initialized, you should observe state to determine when the SDK is ready for authentication and subsequent actions like payments or merchant profile access.

Typical flow:

  1. initialize targeting an environment.

  2. auth to authenticate a merchant using a token.

  3. payments to launch a payment flow or merchant to read config.
