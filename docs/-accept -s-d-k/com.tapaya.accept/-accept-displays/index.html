AcceptDisplays

class AcceptDisplays

Screen-topology surface, for dual-sided ("double-sided") POS hardware.

Use it to discover the customer-facing panel and to decide whether to offer a two-screen checkout at all; pair it with PaymentDisplay on AcceptPayments.setOptions or AcceptPayments.pay to run the payment UI there while the host app keeps the merchant panel:

if (Accept.displays.isDualScreen) {
    Accept.payments.setOptions(display = PaymentDisplay.CustomerFacing)
}

Every method reads the platform live, so a display that is hot-plugged or powered off between calls is reflected immediately. None of them throw.

Obtain an instance via Accept.displays.
