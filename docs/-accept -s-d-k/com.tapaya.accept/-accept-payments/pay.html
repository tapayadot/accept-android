Accept SDK/com.tapaya.accept/AcceptPayments/pay

pay

fun pay(amount: Long, currency: String, paymentToken: String? = null, receiptConfig: PaymentReceiptConfig? = null): Flow<PaymentEvent>

Launches the plugin's payment flow for amount (in the currency's minor unit) in currency, optionally resuming an existing payment identified by paymentToken. Collect the returned Flow to observe PaymentEvent.Creating, PaymentEvent.Created (the payment token is available as soon as this fires, before the plugin is launched), PaymentEvent.Launched, and the terminal PaymentEvent.Result or PaymentEvent.CreationFailed event.

Never throws; failures are reported as PaymentEvent.CreationFailed carrying one of:

  • PaymentInProgress if a previous pay() call is still awaiting a result.

  • NotAuthenticated if AcceptAuth.authenticate has not completed yet.

  • PluginNotReadyForPayments if the plugin app is not authenticated and ready to accept payments.

  • CurrencyNotAvailableForMerchant if currency is not configured for the merchant.

  • AmountBelowMinimum if amount is below the configured minimum for currency.

  • LocationPermissionRequired if the host app has not been granted location permission.

  • LocationUnavailable or LocationTimeout if a device location fix could not be resolved.

  • SessionExpired if the authenticated session has expired.

  • NoInternetConnection if the device has no network connectivity.

  • PaymentCreationFailed wrapping any other unrecognized failure.

Return

a Flow of PaymentEvents representing the lifecycle of the payment request.

Parameters

amount

the amount to charge, in the minor unit of the currency (e.g. cents for USD).

currency

the ISO 4217 currency code.

paymentToken

optional token to resume an existing payment session.

receiptConfig

overrides the default set via setOptions for this payment only; pass null to use that default (see setOptions for what applies if it was never called).
