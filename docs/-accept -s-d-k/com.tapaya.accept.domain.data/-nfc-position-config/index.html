NfcPositionConfig

sealed interface NfcPositionConfig

A hint telling the companion app where this device's NFC antenna is, used to place the "tap here" animation on the tap-to-pay screen.

The companion resolves antenna position on its own (live platform detection, then a bundled device database, then any position the merchant configured in the companion). Provide this only to override that resolution — for example on a device the companion can't detect or has wrong in its database. Unspecified leaves resolution entirely to the companion and never disturbs a position the merchant already configured there.

Set a default via com.tapaya.accept.AcceptPayments.setOptions, or override it for a single payment via com.tapaya.accept.AcceptPayments.pay.
