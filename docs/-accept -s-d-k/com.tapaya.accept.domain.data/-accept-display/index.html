AcceptDisplay

data class AcceptDisplay(val id: Int, val name: String, val isPrimary: Boolean, val isPresentation: Boolean, val widthPx: Int, val heightPx: Int)

A physical or virtual screen the device exposes, as reported by android.hardware.display.DisplayManager.

On dual-sided ("double-sided") POS hardware the merchant-facing panel is the primary display (isPrimary true, id == android.view.Display.DEFAULT_DISPLAY) and the customer-facing panel is a secondary presentation display. Pass id to PaymentDisplay.Specific — or just use PaymentDisplay.CustomerFacing — to run the plugin's payment UI on the customer panel while the host app keeps the merchant panel.
